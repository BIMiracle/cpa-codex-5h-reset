五小时重置唤醒仅适用于 Plus，Business Premium、其他套餐及套餐未知的账号不参与。请求成功不等于上游额度已重置；“新窗口”仅为时间信号判断。

唤醒设置

默认首次请求 + 3 次重试。已知未来重置时间时等待；否则每隔 30 秒重试。

同优先级账号先比较周余量，再比较五小时余量；相差 5 个百分点以内轮询。已有会话在周用量差超过 10 个百分点、或周用量接近但五小时用量差超过 20 个百分点时重新分配。Business Premium 仅返回周额度时也参与；额度未知时仍参与，任一已知窗口耗尽则跳过。默认关闭，保存后生效。如已使用其他账号分配插件，请先按 README 迁移 Key 绑定规则。

默认关闭；运行 CPA 的用户需要有桌面会话。与网页通知同时开启时可能分别提醒。

日期安排

勾选后，中国大陆放假日和普通周末不自动唤醒，调休补班日照常运行。手动“立即唤醒”及其重试仍可执行。

日期安排在保存设置后生效。

排除区间包含首尾两天，只生效一次。明天唤醒覆盖明天的节假日和周末限制；两者互斥，到期恢复默认规则。

月历

周一至周日排列，灰色日期属于相邻月份。选择“排除日期”后，可点选今天起未来 30 天内的起止日期，或使用上方日期输入框。

一二三四五六日

圆形标记为今天；虚线框表示自动跳过，实线框表示一次性日期安排。节假日和补班标注可在相邻月份一并查看。

如果节假日数据获取失败或内容有误，可自行上传年度节假日 JSON 文件。请先预览年份与放假、补班天数，再确认导入。

查看 JSON 数据格式模板

以下为 holiday-cn 格式示例，请按实际年份补齐全年放假日和调休补班日，并保存为 UTF-8 编码的 .json 文件（最大 2 MiB）。

{
  "year": 2026,
  "days": [
    { "date": "2026-10-01", "name": "节日名称", "isOffDay": true },
    { "date": "2026-10-10", "name": "调休补班名称", "isOffDay": false }
  ]
}

year 为年度；date 使用 YYYY-MM-DD；name 为节日或补班名称；isOffDay 为布尔值，true 表示放假，false 表示补班。普通周末无需逐日列出，同一日期不可重复或冲突。示例仅展示格式，不是完整年度数据。

支持提莫年度接口和 holiday-cn 文件。手动导入优先于在线数据；更换文件后须重新预览。导入、清除和数据刷新直接生效。

进行中的任务保留原有重试上限，后续请求使用新模型设置。
